# Business Financial Performance Analysis
Streamlit dashboard with CSV upload support.

## Run in VS Code
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## CSV format
Required columns:
`Fiscal_Year, Revenue, Cost_of_Revenue, R_and_D, Sales_and_Marketing, General_and_Administrative, Operating_Income, Net_Income`

Use a consistent currency and scale. The included sample data is synthetic and for testing only. For real-company analysis, use verified data from official company annual reports.
